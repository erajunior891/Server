## 🚧 Ограничения Платформы Bedrock Edition
В данный момент версия Minecraft Bedrock имеет ряд ограничений по сравнению с Java Edition, что заметно сужает возможности прямого моддинга.

### Направления, вызывающие сложности:
1. **Микрофон / Голосовой чат в игре:**
   - Клиентскую часть Bedrock нельзя свободно модифицировать, из-за чего сделать микрофон, встроенный непосредственно в интерфейс игры (в GUI, а не как отдельный предмет), крайне сложно.
   - *Пути решения:* дальнейшие тесты клиентских возможностей либо использование внешнего приложения (Discord / Mumble), что требует продумывания удобства для игроков с телефонов.

2. **Ограничения интерфейсов и рендеринга:**
   - Кастомные меню реализуются через формы Endstone (`ActionFormData`), так как создание произвольных сундучных интерфейсов (как в Java) на клиенте Bedrock ограничено.
