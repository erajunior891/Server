# 🗺️ Дорожная карта (Roadmap) — Sculk Epidemic SMP

План технической разработки сервера, аддона и плагинов на ядре Endstone. Сюжет сервера строится на основе действий самих игроков.

---

## 🎯 Этап 1: Базовый функционал и Механика (Текущий этап)

### Техническая часть: Аддон и Плагины (Завершено ✅)
- [x] Разработка базового Bedrock-аддона (Behavior & Resource Packs) для версии 1.26.51+.
- [x] Создание предметов: Скалковая Вакцина (`sculk_vaccine`), Скалковая Панацея (`sculk_panacea`).
- [x] Добавление 3 лор-книг (`lore_book_plague`, `lore_book_punishment`, `lore_book_piglin`).
- [x] Разработка Python-плагина для ядра Endstone (`endstone_sculk_epidemic`):
  - [x] Интерактивный UI (`/sculk`).
  - [x] Административные команды (`/sculkadmin`).
  - [x] Оптимизированный менеджер чумы (троттлинг эффектов, пространственная сетка контактов, атомарное сохранение).
  - [x] Сборка wheel (`.whl`) и скрипт установки.

### Структуры и Подготовка Мира (В процессе 🔄)
