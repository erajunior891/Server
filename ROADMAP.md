- [x] Создание уникальных предметов: Скалковая Вакцина (`sculk_vaccine`), Скалковая Панацея (`sculk_panacea`).

- [x] Разработка полнофункционального Python-плагина для ядра Endstone (`endstone_sculk_epidemic`).
- [x] Реализация интерактивного UI на базе форм Bedrock (`/sculk`).
- [x] Реализация административных команд контроля чумы (`/sculkadmin`).
- [x] Настройка автоматической сборки в wheel (`.whl`) и скрипта инсталляции.

- [ ] **Скалковые Мутации**:
  - Игроки на 3 стадии получают временное ночное зрение и ускорение в Deep Dark ценой потери человечности.
- [ ] **Фракционная война**:
  - Раскол сервера на две фракции: «Искатели Очищения» (стремятся искоренить скалк) и «Культ Глубин» (используют скалк как источник силы).
- [ ] **Босс-ивент**:
  - Сюжетный финальный ивент с битвой против Мутировавшего Скалкового Стража в кратере столицы.
