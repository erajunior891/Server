# Плагины для сервера Endstone (Minecraft Bedrock 1.26.51 / 1.21.50+)

В этой папке подготовлены плагины для реализации сценария из папки **Лор**:

## Содержимое папки:
1. **`endstone_sculk_epidemic-1.0.0-py3-none-any.whl`**:
   - Полностью скомпилированный и готовый к работе Python-плагин для Endstone 0.11.12+.
2. **`endstone_sculk_epidemic/`**:
   - Исходный код Python-плагина:
     - `manager.py` — механика 5 этапов чумы, таймеры, симптомы, сохранение в JSON.
     - `gui.py` — формы Bedrock Form API (диагностика, меню лора, рецепты, админка).
     - `lore.py` — тексты произведений ("Скалковая Чума", "Великое Наказание", "Дневник Сэра Пиглинуса").
     - `plugin.py` — регистрация команд `/sculk`, `/sculkadmin` и событий.
3. **`cpp_sculk_plugin/`**:
   - Исходные коды и `CMakeLists.txt` для C++ версии плагина.
4. **`install_to_server.cmd`**:
   - Скрипт в один клик для копирования плагина и мода в директорию сервера (папка сервера не изменяется без вашего запуска или согласия).

## Команды на сервере:
- `/sculk` — открывает главное графическое меню (Диагностика, Лор, Рецепты).
- `/sculk info` — текстовый статус здоровья.
- `/sculk lore <plague|punishment|piglin>` — чтение конкретного фолианта.
- `/sculkadmin infect <игрок> [этап]` — заразить игрока нужным этапом.
- `/sculkadmin cure <игрок> [panacea]` — вылечить игрока.
- `/sculkadmin stage <игрок> <0-4>` — сменить этап.
- `/sculkadmin spread` — запустить вспышку эпидемии.
