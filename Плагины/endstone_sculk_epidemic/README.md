# Плагин: Скалковая Эпидемия (Endstone Plugin)
Для сервера Minecraft Bedrock (версия 1.21.50 - 1.26.51+ с ядром Endstone).

## Возможности плагина:
1. **5 Этапов развития заболевания (по лору)**:
   - **0 Этап (Инкубация)**: Бессимптомное заражение при наступании на скалк или в Deep Dark.
   - **1 Этап**: Наложение Голода и Замедления.
   - **2 Этап**: Замедление II, Слабость, Голод II и внезапная Слепота/Тьма (Darkness).
   - **3 Этап (Эпидемия)**: Заражение передается при контакте с другими игроками! Убийство мобов сеет скалк и скалковые жилы на земле!
   - **4 Этап (Агония)**: Критическое истощение и смертельный урон. При гибели на месте тела прорастает **Скалковый катализатор** (`minecraft:sculk_catalyst`)!
2. **Лечение**:
   - **Временное сдерживание**: Убийство любой враждебной сущности на 90 секунд подавляет симптомы чумы.
   - **Вакцина** (`sculk:sculk_vaccine`): Полное исцеление (0-3 этапы) + 30 минут иммунитета.
   - **Панацея** (`sculk:sculk_panacea`): Мгновенное спасение от 4 стадии + регенерация и длительный иммунитет.
3. **Графический интерфейс Bedrock (Forms API)**:
   - Главное меню `/sculk` с интерактивной диагностикой, чтением фолиантов и книгой рецептов.
4. **Администрирование**:
   - `/sculkadmin infect <игрок> [этап]`
   - `/sculkadmin cure <игрок> [panacea]`
   - `/sculkadmin stage <игрок> <0-4>`
   - `/sculkadmin spread` (массовая вспышка эпидемии)

## Сборка:
Плагин собирается в стандартный `.whl` пакет Python для Endstone.
Для автоматической сборки используйте `build_wheel.cmd`.
