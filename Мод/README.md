# Мод: Скалковая Эпидемия (Sculk Epidemic Bedrock Addon)
Поддерживаемая версия Minecraft Bedrock: **1.21.50 - 1.26.51+**

## Описание предметов:
1. **Вакцина от Скалковой Чумы (`sculk:sculk_vaccine`)**:
   - Изготавливается из: Зелье слабости (`minecraft:potion` слабости) + Осколок эха (`minecraft:echo_shard`).
   - При употреблении снимает симптомы скалковой чумы и вырабатывает временный иммунитет.
2. **Панацея Древних (`sculk:sculk_panacea`)**:
   - Легендарное лекарство, исцеляющее даже 4-ю критическую стадию заболевания.
   - Изготавливается из: Зелье Черепашьей Мощи + Зелье Исцеления.
3. **Фолиант: Скалковая Чума (`sculk:lore_book_plague`)**:
   - Древняя рукопись о природе распространения скалковой инфекции.
4. **Хроника: Великое Наказание (`sculk:lore_book_punishment`)**:
   - Легенды о древней цивилизации, павшей перед темными глубинами.
5. **Дневник Сэра Пиглинуса Пра пра пра пра пра младшего (`sculk:lore_book_piglin`)**:
   - Записки исследователя с точными рецептами создания вакцины и панацеи.

## Файлы аддона:
- `sculk_epidemic_bp/` — папка Behavior Pack (поведение, предметы, крафты)
- `sculk_epidemic_rp/` — папка Resource Pack (текстуры, локализация, модели)
- `Sculk_Epidemic.mcaddon` — единый файл для автоматической установки в Minecraft Bedrock
- `Sculk_Epidemic_BP.mcpack` и `Sculk_Epidemic_RP.mcpack` — раздельные пакеты
